Installing & Initializing the CLI3

How do I install and set up the CLI for the first time?

gcloud / gcp
gcloud init
aws cli
aws configure
Real example 
gcloud init --console-only
Real example 
aws configure
# AWS Access Key ID: AKIA...
# AWS Secret Access Key: ****
# Default region name: us-central1
# Default output format: json

gcloud init walks you through login, project selection and default region/zone in one flow; aws configure just writes ~/.aws/credentials and ~/.aws/config.

How do I log in / authenticate the CLI?

gcloud / gcp
gcloud auth login
aws cli
aws configure sso
Real example 
gcloud auth login --update-adc
Real example 
aws configure sso --profile my-project-id-sso

--update-adc also refreshes Application Default Credentials used by client libraries; SSO login avoids long-lived static keys.

How do I check who I'm currently authenticated as?

gcloud / gcp
gcloud auth list
aws cli
aws sts get-caller-identity
Real example 
gcloud auth list --filter=status:ACTIVE
Real example 
aws sts get-caller-identity --profile my-project-id-sso

Always run this before a destructive command against a project/account you don't usually touch. Gotcha: The #1 cause of accidentally nuking prod is running a command under the wrong active account; check first.

Managing Multiple Accounts & Profiles3

How do I manage multiple accounts or named configurations?

gcloud / gcp
gcloud config configurations create / activate
aws cli
aws configure --profile <name>
Real example 
gcloud config configurations create staging
gcloud config configurations activate staging
Real example 
aws configure --profile staging
# then pass --profile staging on every command

gcloud configurations bundle account + project + region together; AWS profiles live under [profile name] in ~/.aws/config.

How do I switch between configurations/profiles quickly?

gcloud / gcp
gcloud config configurations activate <name>
aws cli
export AWS_PROFILE=<name>
Real example 
gcloud config configurations activate production
Real example 
export AWS_PROFILE=production

Setting AWS_PROFILE as a shell env var avoids typing --profile on every single command in that session.

How do I assume an IAM role in another account/project?

gcloud / gcp
gcloud config set auth/impersonate_service_account
aws cli
aws sts assume-role
Real example 
gcloud config set auth/impersonate_service_account deploy-sa@my-project-id.iam.gserviceaccount.com
Real example 
aws sts assume-role --role-arn arn:aws:iam::111122223333:role/deploy-role --role-session-name web-server-01-deploy

GCP impersonation swaps identity for every subsequent gcloud call; AWS assume-role returns temporary keys you must export yourself.

IAM Basics4

How do I create a service account?

gcloud / gcp
gcloud iam service-accounts create
aws cli
aws iam create-role
Real example 
gcloud iam service-accounts create deploy-sa --display-name="Deploy Service Account"
Real example 
aws iam create-role --role-name deploy-role --assume-role-policy-document file://trust-policy.json

GCP service accounts are identities with keys or Workload Identity; AWS roles are assumed rather than logged into directly.

How do I grant a role/policy to an identity?

gcloud / gcp
gcloud projects add-iam-policy-binding
aws cli
aws iam attach-role-policy
Real example 
gcloud projects add-iam-policy-binding my-project-id \
  --member="serviceAccount:deploy-sa@my-project-id.iam.gserviceaccount.com" \
  --role="roles/compute.admin"
Real example 
aws iam attach-role-policy --role-name deploy-role \
  --policy-arn arn:aws:iam::aws:policy/AmazonEC2FullAccess

Prefer the narrowest predefined/managed role that covers the job over broad admin roles. Gotcha: roles/editor and AdministratorAccess are tempting shortcuts in a demo, but a real security audit will flag them immediately.

How do I create and manage a service account key?

gcloud / gcp
gcloud iam service-accounts keys create
aws cli
aws iam create-access-key
Real example 
gcloud iam service-accounts keys create key.json \
  --iam-account=deploy-sa@my-project-id.iam.gserviceaccount.com
Real example 
aws iam create-access-key --user-name ci-deploy-user

Both are long-lived secrets; only create them when Workload Identity Federation / IAM roles for service accounts aren't an option. Gotcha: A downloaded key.json or access-key pair never expires on its own; rotate or delete it the moment it's no longer needed.

How do I create a human user identity?

gcloud / gcp
; (Cloud Identity/Workspace, then bind an IAM role)
aws cli
aws iam create-user
Real example 
gcloud projects add-iam-policy-binding my-project-id \
  --member="user:jane@example.com" --role="roles/viewer"
Real example 
aws iam create-user --user-name jane

GCP has no "create user" CLI call; human identities come from Google Workspace/Cloud Identity, and you simply bind roles to them.

Creating & Inspecting VMs3

How do I create a VM with a machine type, image, disk, network and tags?

gcloud / gcp
gcloud compute instances create
aws cli
aws ec2 run-instances
Real example 
gcloud compute instances create web-server-01 \
  --zone=us-central1-a --machine-type=e2-medium \
  --image-family=debian-12 --image-project=debian-cloud \
  --boot-disk-size=50GB --boot-disk-type=pd-balanced \
  --network=main-vpc --subnet=web-subnet \
  --tags=http-server,web-tier \
  --metadata-from-file=startup-script=startup.sh
Real example 
aws ec2 run-instances \
  --image-id ami-0abcdef1234567890 --instance-type t3.medium \
  --key-name web-server-key --subnet-id subnet-0f1e2d3c4b5a69870 \
  --security-group-ids sg-0123456789abcdef0 \
  --block-device-mappings 'DeviceName=/dev/xvda,Ebs={VolumeSize=50,VolumeType=gp3}' \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=web-server-01}]' \
  --user-data file://startup.sh

The startup script/user-data runs once on first boot; use it for package installs and agent bootstrapping, not app deploys. Gotcha: Boot disk defaults are small; set the size explicitly or you'll be resizing under pressure later.

How do I list all VMs, and describe one in detail?

gcloud / gcp
gcloud compute instances list / describe
aws cli
aws ec2 describe-instances
Real example 
gcloud compute instances list --filter="zone:us-central1-a"
gcloud compute instances describe web-server-01 --zone=us-central1-a
Real example 
aws ec2 describe-instances \
  --filters "Name=tag:Name,Values=web-server-01"

describe/describe-instances return the full JSON resource; pipe through --format or --query to pull just what you need.

How do I filter and format list output for scripting?

gcloud / gcp
--filter / --format
aws cli
--query / --output
Real example 
gcloud compute instances list \
  --filter="status=RUNNING AND labels.tier=web" \
  --format="table(name,zone,machineType.basename())"
Real example 
aws ec2 describe-instances \
  --filters Name=instance-state-name,Values=running \
  --query 'Reservations[].Instances[].[InstanceId,InstanceType]' \
  --output table

--format/--query turn raw JSON into pipeable one-liners; essential once you're scripting instead of clicking around a console.

Power State: Start, Stop, Reset, Delete4

How do I start and stop a VM?

gcloud / gcp
gcloud compute instances start / stop
aws cli
aws ec2 start-instances / stop-instances
Real example 
gcloud compute instances stop web-server-01 --zone=us-central1-a
gcloud compute instances start web-server-01 --zone=us-central1-a
Real example 
aws ec2 stop-instances --instance-ids i-0abcd1234efgh5678
aws ec2 start-instances --instance-ids i-0abcd1234efgh5678

Stopping releases the vCPU/RAM billing but the boot disk keeps billing until the VM is deleted. Gotcha: Stopping a VM does NOT release its ephemeral or static external IP on some configs; you can still be billed for a reserved static IP sitting idle.

How do I suspend (RAM-preserving pause) and resume a VM?

gcloud / gcp
gcloud compute instances suspend / resume
aws cli
aws ec2 stop-instances --hibernate / start-instances
Real example 
gcloud compute instances suspend web-server-01 --zone=us-central1-a
gcloud compute instances resume web-server-01 --zone=us-central1-a
Real example 
aws ec2 stop-instances --instance-ids i-0abcd1234efgh5678 --hibernate
aws ec2 start-instances --instance-ids i-0abcd1234efgh5678

Suspend/hibernate writes RAM to disk so the OS resumes exactly where it left off; needs hibernation enabled at launch on AWS.

How do I hard-reset a hung VM?

gcloud / gcp
gcloud compute instances reset
aws cli
aws ec2 reboot-instances
Real example 
gcloud compute instances reset web-server-01 --zone=us-central1-a
Real example 
aws ec2 reboot-instances --instance-ids i-0abcd1234efgh5678

Equivalent to pulling the power and plugging it back in; no graceful shutdown, use only when the OS is unresponsive.

Destructive

How do I permanently delete a VM?

gcloud / gcp
gcloud compute instances delete
aws cli
aws ec2 terminate-instances
Real example 
gcloud compute instances delete web-server-01 --zone=us-central1-a
Real example 
aws ec2 terminate-instances --instance-ids i-0abcd1234efgh5678

By default this also deletes the boot disk unless it was created with --no-boot-disk-auto-delete / a DeleteOnTermination=false mapping. Gotcha: There is no undo; snapshot the disk first if there's any chance you'll need the data again.

Connecting to a VM2

How do I SSH into a VM?

gcloud / gcp
gcloud compute ssh
aws cli
ssh -i key.pem / aws ssm start-session
Real example 
gcloud compute ssh web-server-01 --zone=us-central1-a
Real example 
ssh -i web-server-key.pem ec2-user@<public-ip>
# or, no open SSH port needed:
aws ssm start-session --target i-0abcd1234efgh5678

gcloud compute ssh auto-generates and pushes an OS Login/project SSH key for you; AWS needs either an open port 22 + key pair, or the SSM agent.

How do I connect to a private VM with no public IP or open SSH port?

gcloud / gcp
gcloud compute ssh --tunnel-through-iap
aws cli
aws ssm start-session
Real example 
gcloud compute ssh web-server-01 --zone=us-central1-a --tunnel-through-iap
Real example 
aws ssm start-session --target i-0abcd1234efgh5678

Both tunnel through the provider's control plane instead of opening an inbound firewall rule; the modern default for prod access. Gotcha: IAP tunneling needs the iap.tunnelResourceAccessor role and a firewall rule allowing 35.235.240.0/20 on tcp:22.

Resizing, Zone Changes & Live Migration3

How do I change a VM's machine type?

gcloud / gcp
gcloud compute instances set-machine-type
aws cli
aws ec2 modify-instance-attribute
Real example 
gcloud compute instances stop web-server-01 --zone=us-central1-a
gcloud compute instances set-machine-type web-server-01 \
  --zone=us-central1-a --machine-type=e2-standard-4
gcloud compute instances start web-server-01 --zone=us-central1-a
Real example 
aws ec2 stop-instances --instance-ids i-0abcd1234efgh5678
aws ec2 modify-instance-attribute --instance-id i-0abcd1234efgh5678 \
  --instance-type '{"Value": "t3.large"}'
aws ec2 start-instances --instance-ids i-0abcd1234efgh5678

On both clouds a resize needs the VM stopped first; this is one of the must-stop operations, not a live migration.

How do I move a VM to a different zone? (there's no single command)

gcloud / gcp
gcloud compute instances move  (limited) / snapshot-and-recreate
aws cli
create AMI → launch in new AZ
Real example 
# 1. Snapshot the boot disk
gcloud compute disks snapshot web-server-01 --zone=us-central1-a \
  --snapshot-names=web-server-01-migrate
# 2. Create a new disk from the snapshot in the target zone
gcloud compute disks create web-server-01 \
  --zone=us-central1-b --source-snapshot=web-server-01-migrate
# 3. Delete the old VM (keep-disk not needed, disk already copied), create the new one
gcloud compute instances create web-server-01 \
  --zone=us-central1-b --disk=name=web-server-01,boot=yes
Real example 
# 1. Create an AMI from the running instance
aws ec2 create-image --instance-id i-0abcd1234efgh5678 --name web-server-01-migrate
# 2. Launch a new instance from that AMI in the target AZ/subnet
aws ec2 run-instances --image-id ami-0fedcba9876543210 \
  --subnet-id subnet-0a1b2c3d4e5f67890 --instance-type t3.medium
# 3. Terminate the old instance once traffic has cut over

gcloud compute instances move only works within the same region between zones for a narrow set of configs; the reliable, general path on both clouds is snapshot/image → recreate. Gotcha: Plan for a new IP address and a DNS/load-balancer update as part of this; it's rarely just a disk copy.

What's the difference between live migration and a must-stop operation?

gcloud / gcp
on-host maintenance policy
aws cli
no live migration for standard EC2
Real example 
gcloud compute instances create web-server-01 \
  --maintenance-policy=MIGRATE   # default for most machine types
Real example 
# AWS reboots/replaces the instance during host maintenance events instead of migrating it live
aws ec2 describe-instance-status --instance-ids i-0abcd1234efgh5678

GCP transparently live-migrates VMs off a host during infrastructure maintenance with no downtime; standard EC2 instances get a scheduled reboot notice instead.

Instance Templates & Managed Instance Groups / ASGs4

How do I create a reusable instance template?

gcloud / gcp
gcloud compute instance-templates create
aws cli
aws ec2 create-launch-template
Real example 
gcloud compute instance-templates create web-template-v1 \
  --machine-type=e2-medium --image-family=debian-12 \
  --image-project=debian-cloud --tags=http-server
Real example 
aws ec2 create-launch-template \
  --launch-template-name web-template-v1 \
  --launch-template-data file://launch-template.json

Templates are immutable snapshots of launch config; you version them (v1, v2...) rather than editing in place.

How do I create a Managed Instance Group / Auto Scaling Group from a template?

gcloud / gcp
gcloud compute instance-groups managed create
aws cli
aws autoscaling create-auto-scaling-group
Real example 
gcloud compute instance-groups managed create web-mig \
  --template=web-template-v1 --size=3 --zone=us-central1-a
Real example 
aws autoscaling create-auto-scaling-group \
  --auto-scaling-group-name web-asg \
  --launch-template LaunchTemplateName=web-template-v1,Version='$Latest' \
  --min-size 2 --max-size 6 --desired-capacity 3 \
  --vpc-zone-identifier subnet-0f1e2d3c4b5a69870

Both are the standard way to run a fleet instead of hand-managing individual VMs.

How do I roll out a new template version without downtime?

gcloud / gcp
gcloud compute instance-groups managed rolling-action start-update
aws cli
aws autoscaling start-instance-refresh
Real example 
gcloud compute instance-groups managed rolling-action start-update web-mig \
  --version=template=web-template-v2 --zone=us-central1-a \
  --max-surge=1 --max-unavailable=0
Real example 
aws autoscaling start-instance-refresh \
  --auto-scaling-group-name web-asg \
  --preferences 'MinHealthyPercentage=90,InstanceWarmup=120'

max-surge/max-unavailable (and MinHealthyPercentage on AWS) control how aggressively old instances are replaced with new ones.

How do I attach an autoscaler policy based on CPU or load?

gcloud / gcp
gcloud compute instance-groups managed set-autoscaling
aws cli
aws autoscaling put-scaling-policy
Real example 
gcloud compute instance-groups managed set-autoscaling web-mig \
  --zone=us-central1-a --max-num-replicas=10 \
  --target-cpu-utilization=0.6 --cool-down-period=90
Real example 
aws autoscaling put-scaling-policy \
  --auto-scaling-group-name web-asg --policy-name cpu-target-60 \
  --policy-type TargetTrackingScaling \
  --target-tracking-configuration file://cpu-policy.json

Target-tracking policies (target CPU %) are almost always a better starting point than manual step-scaling rules.

Metadata, Startup Scripts & OS Login2

How do I update metadata or a startup script on an existing VM?

gcloud / gcp
gcloud compute instances add-metadata
aws cli
aws ec2 modify-instance-metadata-options / re-run via SSM
Real example 
gcloud compute instances add-metadata web-server-01 \
  --zone=us-central1-a \
  --metadata-from-file=startup-script=startup-v2.sh
Real example 
# EC2 user-data only runs on first boot by default; to re-run, use SSM Run Command
aws ssm send-command --instance-ids i-0abcd1234efgh5678 \
  --document-name "AWS-RunShellScript" \
  --parameters 'commands=["bash /opt/deploy.sh"]'

Editing GCP metadata doesn't auto-re-run the script on a running VM either; you still need a reboot or an SSM-style push for changes to take effect.

How do I enable OS Login and add an SSH key?

gcloud / gcp
gcloud compute instances add-metadata --metadata enable-oslogin=TRUE
aws cli
aws ec2-instance-connect send-ssh-public-key
Real example 
gcloud compute instances add-metadata web-server-01 \
  --zone=us-central1-a --metadata=enable-oslogin=TRUE
gcloud compute os-login ssh-keys add --key-file=~/.ssh/id_ed25519.pub
Real example 
aws ec2-instance-connect send-ssh-public-key \
  --instance-id i-0abcd1234efgh5678 --availability-zone us-east-1a \
  --instance-os-user ec2-user --ssh-public-key file://id_ed25519.pub

OS Login ties SSH access to IAM identity instead of baked-in project-wide keys; the safer default for teams.

Spot/Preemptible Instances & Health Checks2

How do I create a low-cost preemptible/spot VM?

gcloud / gcp
gcloud compute instances create --provisioning-model=SPOT
aws cli
aws ec2 run-instances --instance-market-options
Real example 
gcloud compute instances create batch-worker-01 \
  --zone=us-central1-a --machine-type=e2-standard-4 \
  --provisioning-model=SPOT --instance-termination-action=DELETE
Real example 
aws ec2 run-instances --image-id ami-0abcdef1234567890 \
  --instance-type c6i.xlarge \
  --instance-market-options 'MarketType=spot,SpotOptions={MaxPrice=0.05}'

70-90% cheaper than on-demand, but the provider can reclaim the instance with only ~30s (GCP) to 2min (AWS) notice. Gotcha: Never put stateful, single-replica workloads on spot/preemptible capacity; design for interruption from day one.

How do I attach a health check to an instance group for auto-healing?

gcloud / gcp
gcloud compute health-checks create + instance-groups managed set-autohealing
aws cli
ASG health check type ELB + target group health check
Real example 
gcloud compute health-checks create http web-health-check --port=80 --request-path=/healthz
gcloud compute instance-groups managed set-autohealing web-mig \
  --health-check=web-health-check --initial-delay=300 --zone=us-central1-a
Real example 
aws autoscaling update-auto-scaling-group \
  --auto-scaling-group-name web-asg \
  --health-check-type ELB --health-check-grace-period 300

Auto-healing replaces individual unhealthy instances automatically; separate from the load balancer's own health checks, which just stop routing to them.

Object Storage Buckets5
Destructive

How do I create, list and delete a bucket?

gcloud / gcp
gsutil mb / ls / rm  (or gcloud storage)
aws cli
aws s3 mb / ls / rb
Real example 
gcloud storage buckets create gs://my-project-id-assets --location=us-central1 --default-storage-class=STANDARD
gcloud storage buckets list
gcloud storage buckets delete gs://my-project-id-assets
Real example 
aws s3 mb s3://my-project-id-assets --region us-east-1
aws s3 ls
aws s3 rb s3://my-project-id-assets --force

gcloud storage is the modern replacement for gsutil (same functionality, faster); both still work. Gotcha: Bucket names are globally unique across the entire cloud provider, not just your project/account.

How do I set a bucket's storage class and lifecycle rules?

gcloud / gcp
gcloud storage buckets update --lifecycle-file
aws cli
aws s3api put-bucket-lifecycle-configuration
Real example 
gcloud storage buckets update gs://my-project-id-assets \
  --lifecycle-file=lifecycle.json
# lifecycle.json: {"rule":[{"action":{"type":"SetStorageClass","storageClass":"NEARLINE"},
#   "condition":{"age":30}}]}
Real example 
aws s3api put-bucket-lifecycle-configuration \
  --bucket my-project-id-assets \
  --lifecycle-configuration file://lifecycle.json

Lifecycle rules automatically transition or delete objects by age; set these up before the bucket fills with logs nobody reads.

How do I enable versioning on a bucket?

gcloud / gcp
gcloud storage buckets update --versioning
aws cli

How do I mount a freshly-attached disk inside the VM (full walkthrough)?

gcloud / gcp
lsblk → mkfs → mkdir → mount → /etc/fstab
aws cli
lsblk → mkfs → mkdir → mount → /etc/fstab (identical; this is OS-level, not cloud-specific)
Real example 
# 1. Find the new device
lsblk
# 2. Format it (ONLY on a brand-new empty disk!)
sudo mkfs.ext4 -m 0 -F /dev/sdb
# 3. Create a mount point
sudo mkdir -p /mnt/data
# 4. Mount it
sudo mount -o discard,defaults /dev/sdb /mnt/data
# 5. Get the UUID and make it persist across reboots
sudo blkid /dev/sdb
echo 'UUID=xxxx-xxxx  /mnt/data  ext4  discard,defaults,nofail  0  2' | sudo tee -a /etc/fstab
sudo mount -a   # verify fstab entry is valid before rebooting
# 6. After a later disk resize:
sudo resize2fs /dev/sdb
Real example 
# identical steps; just a different device name (/dev/xvdf)
lsblk
sudo mkfs.ext4 -m 0 -F /dev/xvdf
sudo mkdir -p /mnt/data
sudo mount -o discard,defaults /dev/xvdf /mnt/data
sudo blkid /dev/xvdf
echo 'UUID=xxxx-xxxx  /mnt/data  ext4  discard,defaults,nofail  0  2' | sudo tee -a /etc/fstab
sudo mount -a
sudo growpart /dev/xvdf 1 && sudo resize2fs /dev/xvdf1

Use the UUID (not /dev/sdb) in fstab; device names can shift on reboot, especially with multiple attached disks. Gotcha: mkfs.ext4 is destructive on a disk that already has data; only run it on a genuinely new, empty volume, never on one restored from snapshot.

How do I deploy an API Gateway and lock the backend so only the gateway can reach it?

gcloud / gcp
gcloud api-gateway api-configs create + firewall rule scoped to the gateway's egress
aws cli
aws apigateway create-rest-api + VPC Link + security group on the NLB
Real example 
# 1. Create the API config and deploy the gateway
gcloud api-gateway api-configs create web-api-cfg-v1 \
  --api=web-api --openapi-spec=openapi.yaml
gcloud api-gateway gateways create web-gateway \
  --api=web-api --api-config=web-api-cfg-v1 --location=us-central1
# 2. Restrict the backend to only accept traffic from the gateway's
#    serverless VPC connector range (not from the whole internet/VPC)
gcloud compute firewall-rules create allow-from-gateway-only \
  --network=main-vpc --direction=INGRESS --action=ALLOW \
  --rules=tcp:8080 --source-ranges=10.8.0.0/28 \
  --target-tags=api-backend
Real example 
# 1. Create a VPC Link so API Gateway can reach a private NLB
aws apigateway create-vpc-link \
  --name web-vpc-link --target-arns arn:aws:elasticloadbalancing:...:loadbalancer/net/web-nlb/abc123
aws apigateway create-rest-api --name web-api
# 2. Restrict the backend security group to only the NLB/VPC Link's ENIs,
#    not 0.0.0.0/0; i.e. remove any public ingress rule
aws ec2 revoke-security-group-ingress --group-id sg-0backend1234567 \
  --ip-permissions 'IpProtocol=tcp,FromPort=8080,ToPort=8080,IpRanges=[{CidrIp=0.0.0.0/0}]'

  --ip-permissions 'IpProtocol=tcp,FromPort=8080,ToPort=8080,IpRanges=[{CidrIp=10.128.0.0/20}]'

The pattern on both clouds is the same: give the gateway a known, narrow egress IP/CIDR (a VPC connector on GCP, a VPC Link's ENIs on AWS), then scope the backend's firewall/security-group to allow only that range; never the whole internet. Gotcha: It's easy to deploy the gateway correctly but forget to actually remove the backend's old public-facing rule; always audit for a leftover 0.0.0.0/0 ingress rule after locking things down.

Cloud ↔ Cloud (AWS ↔ GCP)2

How do I move a VM's disk from AWS to GCP (or back)?

gcloud / gcp
export AMI → gsutil/gcloud storage transfer → gcloud compute images import
aws cli
export the disk → aws s3 sync → aws ec2 import-image
Real example 
# 1. Export the AWS AMI to a VMDK in an S3 bucket (AWS VM Import/Export in reverse)
aws ec2 export-image --image-id ami-0abcdef1234567890 \
  --s3-export-location S3Bucket=my-project-id-assets,S3Prefix=exports/
# 2. Move the exported image from S3 to GCS
gcloud storage cp s3://my-project-id-assets/exports/export.vmdk gs://my-project-id-assets/imports/
# 3. Import into GCP
gcloud compute images import web-server-01-from-aws \
  --source-file=gs://my-project-id-assets/imports/export.vmdk --os=debian-12
Real example 
# reverse direction: GCP image export → GCS → S3 → aws ec2 import-image
gcloud compute images export --destination-uri=gs://my-project-id-assets/exports/disk.vmdk \
  --image=web-server-01-golden
gcloud storage cp gs://my-project-id-assets/exports/disk.vmdk s3://my-project-id-assets/imports/
aws ec2 import-image --disk-containers 'Description=web-server-01,Format=vmdk,UserBucket={S3Bucket=my-project-id-assets,S3Key=imports/disk.vmdk}'

There's no direct cloud-to-cloud image API; object storage is always the intermediate hop, and format (VMDK/VHD/RAW) needs to match what the destination importer accepts. Gotcha: For large disks, moving the export through the public internet can dominate your migration timeline; use Interconnect/Direct Connect or a physical transfer appliance for multi-terabyte migrations.

Database Migration2

How do I set up an online database migration with minimal downtime?

gcloud / gcp
Database Migration Service: connection profile → migration job → promote
aws cli
AWS DMS: replication instance → endpoints → replication task
Real example 
gcloud database-migration connection-profiles create web-app-db-source \
  --region=us-central1 --mysql-host=203.0.113.20 --mysql-port=3306
gcloud database-migration migration-jobs create web-app-db-migration \
  --region=us-central1 --source=web-app-db-source --destination=web-app-db \

Real example

Storage Migration Best Practices1

Migration best-practices checklist

  • Assessment: inventory every workload, its dependencies, and its actual (not assumed) resource usage before picking a target size.
  • Network bandwidth planning: estimate transfer time at your real available bandwidth, not the link's advertised max; it's almost always lower.
  • Downtime window: agree the maximum acceptable downtime with stakeholders before choosing an offline vs. continuous-replication strategy.
  • Rollback plan: keep the source system intact and untouched until the target has been validated in production for a defined burn-in period.
  • Cost comparison: model steady-state cost at the target's real usage pattern, not the source's; cloud pricing structures (e.g. IOPS, egress) differ enough to surprise you.
  • Data validation: checksum or row-count reconcile source vs. target after cutover, not just "the migration job reported success".

Linux In-VM Service Management

Once you're inside the VM it's the same Linux either way. Every systemctl/supervisorctl command a fresher needs, plus the everyday process, disk and network tools.

These commands run the same way inside a GCP or AWS VM: the OS underneath doesn’t care who’s billing you for it. The GCP / AWS switch above has no effect on this section.

systemctl9

How do I start, stop, restart and reload a service?

shell
systemctl start|stop|restart|reload <service>
Real example 
sudo systemctl restart nginx
sudo systemctl reload nginx   # graceful, drops no connections; if the service supports it

reload asks the process to re-read its config via SIGHUP without dropping connections, but only works if the service supports it; restart always works.

How do I check a service's status, and whether it's active/enabled?

shell
systemctl status|is-active|is-enabled <service>
Real example 
sudo systemctl status nginx
systemctl is-active nginx
systemctl is-enabled nginx

is-active/is-enabled return a script-friendly exit code (0 or 1); use them in health-check scripts instead of grepping status output.

How do I make a service start automatically on boot (and undo that)?

shell
systemctl enable|disable <service>
Real example 
sudo systemctl enable nginx
sudo systemctl disable nginx
# do both at once: sudo systemctl enable --now nginx

enable only creates a boot-time symlink; it does not start the service right now. Pair it with start, or use --now to do both.

How do I completely block a service from starting, even manually?

shell
systemctl mask|unmask <service>
Real example 
sudo systemctl mask sendmail
sudo systemctl unmask sendmail

mask replaces the unit file with a symlink to /dev/null; stronger than disable, which only stops it starting automatically at boot.

How do I make systemd pick up a unit file I just edited?

shell
systemctl daemon-reload
Real example 
sudo vim /etc/systemd/system/myapp.service
sudo systemctl daemon-reload
sudo systemctl restart myapp

Without daemon-reload, systemd keeps using its old in-memory copy of the unit file. Gotcha: Forgetting daemon-reload after editing a unit is probably the single most common systemd mistake; always run it before restarting.

How do I list all loaded units, and every installed unit file?

shell
systemctl list-units|list-unit-files
Real example 
systemctl list-units --type=service --state=running
systemctl list-unit-files --type=service | grep enabled

list-units shows current runtime state; list-unit-files shows everything installed regardless of whether it's currently loaded.

How do I override part of a unit file without editing the vendor's original?

shell
systemctl edit <service>
Real example 
sudo systemctl edit nginx
# opens /etc/systemd/system/nginx.service.d/override.conf; add:
# [Service]
# Restart=always
sudo systemctl daemon-reload && sudo systemctl restart nginx

This "drop-in" override survives package upgrades that would otherwise overwrite a hand-edited unit file.

How do I follow a service's logs live, or see logs since a point in time?

shell
journalctl -u <service> -f  /  journalctl --since
Real example 
sudo journalctl -u nginx -f
sudo journalctl -u nginx --since "2026-09-10 00:00:00" --until "2026-09-10 06:00:00"

journalctl -u filters to exactly one unit's logs; far faster than grepping through /var/log by hand.

How do I write a custom .service unit file from scratch?

shell
/etc/systemd/system/<name>.service
Real example 
sudo tee /etc/systemd/system/myapp.service << 'UNIT'
[Unit]
Description=My App
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/node /opt/myapp/server.js
Restart=on-failure
User=myapp
WorkingDirectory=/opt/myapp

[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl daemon-reload
sudo systemctl enable --now myapp

enable --now both enables the service at boot AND starts it immediately; the one-liner you actually want most of the time.

supervisorctl4

How do I check status and start/stop/restart a program under supervisor?

shell
supervisorctl status|start|stop|restart <program>
Real example 
supervisorctl status
sudo supervisorctl restart myapp

Unlike systemctl, supervisor programs are plain user-space processes that supervisord itself owns and restarts on crash; not systemd units.

How do I pick up a new or changed program config?

shell
supervisorctl reread + update
Real example 
sudo supervisorctl reread
sudo supervisorctl update

reread only diffs configs against what's running; update actually applies the changes (adds/removes/restarts affected programs); always run both together.

How do I tail a supervised program's logs live?

shell
supervisorctl tail -f <program> [stdout|stderr]
Real example 
supervisorctl tail -f myapp stderr

Supervisor captures stdout/stderr into its own log files by default; this is the fast way to watch them without hunting for the path.

How do I add a new program to supervisor, and start supervisord itself?

shell
edit a conf.d file, then reread + update
Real example 
sudo tee /etc/supervisor/conf.d/myapp.conf << 'CONF'
[program:myapp]
command=/usr/bin/node /opt/myapp/server.js
directory=/opt/myapp
autostart=true
autorestart=true
user=myapp
stdout_logfile=/var/log/myapp/out.log
stderr_logfile=/var/log/myapp/err.log
CONF
sudo supervisorctl reread && sudo supervisorctl update
# start the daemon itself if it isn't already running:
sudo supervisord -c /etc/supervisor/supervisord.conf

autorestart=true is supervisor's core value-add over a bare background process; it comes back automatically after a crash.

How do I see running processes and live resource usage?

shell
ps / top / htop
Real example 
ps aux | grep node
top
htop   # friendlier top, if installed

ps aux is a one-shot snapshot; top/htop refresh live; reach for top first when a box just feels slow.

shell
df -h / du -sh
Real example 
df -h
du -sh /var/log/* | sort -h

df shows filesystem-level free space; du shows what's actually consuming it directory by directory; you need both to diagnose and fix a full disk.

How do I check memory usage, including swap?

shell
free -m
Real example 
free -m
free -h   # human-readable units

How do I check open ports and active network connections?

shell
ss / netstat
Real example 
sudo ss -tulpn

Scheduling, Backgrounding & Killing Processes4

How do I schedule a recurring job for the current user?

shell
crontab -e
Real example 
crontab -e
# add:
0 2 * * * /opt/myapp/nightly-backup.sh >> /var/log/nightly-backup.log 2>&1

Always redirect output to a log file; a cron job's stdout/stderr otherwise vanishes silently unless system mail is configured.

How do I keep a process running after I log out of my SSH session?

shell
nohup ... & / disown
Real example 
nohup /opt/myapp/server.js > out.log 2>&1 &
disown

Fine for a quick manual test, but nohup doesn't restart a crashed process; use systemd or supervisor for anything you actually depend on.

How do I stop a runaway or hung process?

shell
kill / killall / pkill
Real example 
kill -15 1234        # graceful (SIGTERM); try this first
kill -9 1234         # forceful (SIGKILL); last resort
killall node
pkill -f "node server.js"

Always try SIGTERM (the default, -15) first and give the process a moment to shut down cleanly before reaching for -9.

How do I check or enable swap space?

shell
swapon / free -m
Real example 
free -m   # shows current swap usage
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Swap is a safety net against OOM kills, not a substitute for right-sizing memory; a VM that's constantly swapping needs a bigger machine type/instance, not more swap.
